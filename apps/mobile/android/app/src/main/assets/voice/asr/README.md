# Final-pass English transcription

The app bundles the encoder, decoder and token table from sherpa-onnx's
int8 Whisper base.en export at revision `59eea950fc76df2453efb57e6c0fd334548e8ffe`.
The encoder and decoder use shorter local filenames. OpenAI makes the code
and model weights available under the MIT license included here.

- [Pinned ONNX export](https://huggingface.co/csukuangfj/sherpa-onnx-whisper-base.en/tree/59eea950fc76df2453efb57e6c0fd334548e8ffe)
- [OpenAI Whisper model and license](https://github.com/openai/whisper#license)
