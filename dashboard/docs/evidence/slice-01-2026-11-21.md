- **Device:** Pixel 10 Pro XL, Android 17 (API 37), debug arm64 build
- **PC:** Ubuntu 22.04, headless Chrome (lead, via playwright-core) + owner's browser
- **Network:** PC on the **phone's Wi-Fi hotspot** (`ap_br_wlan2` 10.181.249.119/24, PC 10.181.249.40); phone's own Wi-Fi is public with client isolation (PC↔phone over that Wi-Fi impossible: ARP fails). WAN reachable via phone.

## Bugs found on device and fixed
1. Preview frozen after QR scanner → SurfaceProducer callbacks + single camera owner.
2. **Telemetry egress** to `firebaselogging.googleapis.com` from ML Kit (mobile_scanner) → removed; QR decoded with ZXing in our CameraSession; dependency grep clean.
3. Camera "previewing" with zero frames → state derived from real frames + 3 s watchdog.
4. ICE failed over phone hotspot (libwebrtc network monitor ignores tether interface) → `disableNetworkMonitor` + cellular ignore mask (ADR 0002 notes).
